# Support

## Using repo-roast

- Start with [README.md](README.md) — install, configuration, usage examples,
  and the full flags table.
- `repo-roast roast --help` documents every flag from the tool itself.
- `--dry-run` is the fastest way to check the GitHub half in isolation: it
  needs a `GITHUB_TOKEN` but no `LLM_API_KEY`.

## Found a bug, or want a feature?

[Open an issue](https://github.com/Amayyas/repo-roast/issues/new). Include the
command you ran, what you expected, and what happened instead.
